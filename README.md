 Андерзянов Ильяс

## Описание
Приложение для ведения личного дневника погоды. Позволяет фиксировать температуру, наличие осадков и текстовое описание на конкретную дату. Данные сохраняются локально в формате JSON.

## Функционал
- Добавление записей с валидацией (дата, числовая температура).
- Фильтрация по минимальной температуре.
- Автоматическое сохранение и загрузка данных.

## Запуск
1. Установите Python 3.x.
2. Скачайте файл `weather_diary.py`.
3. Запустите через терминал: `python weather_diary.py`.

## Примеры использования
- Введите `01.05.2024`, `+15`, `Солнечно`, снимите галочку "Осадки" -> Нажмите "Добавить".
- В поле фильтра введите `10` -> Будут показаны только записи теплее +10°C.
